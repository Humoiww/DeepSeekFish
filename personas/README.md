# 独立人格模块

`active.json` 选择当前人格目录。`mesugaki/prompt.md` 是 ififi2017/hybrid-catgirl-skill 的 `SKILL.md` 中「雌小鬼模式」完整原文段落；没有生成、翻译或改写人格语气和台词。来源、固定 revision、提取位置及 MIT 许可证在同目录。此文件是角色数据，不是项目管理工具的技能或执行指令。

`mesugaki/appearance.txt` 保留本项目此前由用户设定图确定的鲸酱外观文本，原样从 `src/character.ts` 移入。它和人格语气独立：切换性格不更换蓝发鲸酱外观。旧 `prompts/whalechan-rp.txt` 不再作为当前人格加载。

改动人格文件后重启 QQ/WebUI 服务生效。保持来源文件原文；用户未授权自行改写人格 prompt。提示词不授予执行、凭据或网络权限。
