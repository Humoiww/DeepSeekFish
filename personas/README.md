# 独立人格模块

active.json 选择当前人格。按用户本轮明确要求，mesugaki/prompt.md 采用精简的鲸酱人格：住在服务器里的可爱大肥鱼、嘴硬爱逗人、实际亲近心软。没有示范台词或固定开场白。

原先导入的 GitHub 雌小鬼段落完整保存在 upstream.md；固定来源版本和 MIT 许可证保留。本轮不再把原文里的猫娘触发词、台词示例和边界清单直接塞进日常聊天。active prompt 是经用户授权的适配，不标为逐字导入。

appearance.txt 保留既有鲸酱外观，生图沿用原始参考图。QQ 日常聊天仅加载精简人格；外观和参考图规则留在生图链路。工具提示只交代记忆、人物资料、精力和生图能力的位置，具体措辞由模型生成。代码中的账户隔离和账本不由人格控制。

WebUI 侧栏「人格与提示词」可分块编辑；保存后以 `runtime/data/persona.json` 覆盖默认人格，下一轮立即生效。当前 system 和最近一次实际模型请求可在同一界面查看。此覆盖文件随私有迁移包迁移，仓库原文与来源保留。
