# 鲸酱角色提示词

`whalechan-rp.txt` 是早期人设备份，当前不再加载。当前人格的原文来源和配置见 [personas](../personas/README.md)。外观描述与自画像规则在 `src/character.ts`，用户提供的原始设定集保存在 [assets/character/whalechan-reference.png](../assets/character/whalechan-reference.png)，随 Git 分发。可选本机覆盖图仍放在 `runtime/character/whalechan-reference.png`，覆盖文件不随 Git 上传。

人设参考 [Neko3000/deepseek-whalechan 的角色档案](https://github.com/Neko3000/deepseek-whalechan#-whale-chan-character-profile)，改写为简短中文 RP，并加入“先完成任务、不虚报执行、不改变权限”的项目行为约束。不是安装或执行该仓库的 Skills，不采用其批量生成、外部付费 API 或多智能体工作流。
