# 人民币日额度

默认 `dailyCny=5`，QQ、网页、新闻、空间文案、记忆回顾和探索共用现有 SQLite 账本。`groupDailyCny=0` 表示无额外群限额；正数仍同时受全局额度限制。香港时间 00:00 自然切日。WebUI「连接与设置」保存后即时生效，重启保留。旧 dailyTokens/groupDailyTokens 忽略，输入/输出/缓存 token 保留为统计。

## 单价与结算

2026-11-05 核对 [DeepSeek 人民币定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：

| 模型 | 缓存输入 / 百万 token | 非缓存输入 / 百万 token | 输出 / 百万 token |
| --- | ---: | ---: | ---: |
| Flash 高峰 | ¥0.04 | ¥2 | ¥8 |
| Flash 错峰 | ¥0.02 | ¥1 | ¥4 |
| V4 Pro 高峰 | ¥0.30 | ¥9 | ¥27 |
| V4 Pro 错峰 | ¥0.15 | ¥4.5 | ¥13.5 |

Flash 的现有模型别名沿用同价；未配置单价的新模型拒绝请求，避免虚报免费。单价实现在 `src/budget/pricing.ts`，每笔保留版本、来源、模型、时间和单价快照，后续改模型不改变旧账。

北京时间周一至周五（法定节假日除外）09:00–12:00、14:00–18:00 为高峰，其余错峰。已收录[国务院 2026 年节假日安排](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)；未收录年份的潜在高峰日按高价估算并标注。平台更新价格或日历时需维护单价表。

模型费用 = 缓存输入 × 缓存价 + 非缓存输入 × 非缓存价 + 输出 × 输出价。内部用整数纳元，避免浮点累计。请求前按所有输入未命中缓存、最大输出和最高时段价原子预留；有 usage 后退回差额。价格按请求开始时间选取，跨定价边界的服务端结算时点无法从 usage 确认；这里是本地费用核算，并非官方账单同步。

- `confirmed`：输入、输出、缓存划分与当日单价齐全，按返回用量核算。
- `estimated`：缓存划分缺失或节假日日历缺失，按较高价估算，不伪造缓存命中。
- `held`：请求进行中，保留足额预留。
- `unknown`：超时、断连、进程中断或旧记录证据缺失，无法确认实际费用，保留预留。
- `refunded`：联网明确未计费，退还预留。相同 ID 不重复结算。

[Search/Fetch](https://api-docs.deepseek.com/zh-cn/guides/search/) 按成功且非空请求 ¥0.005 / 次直接入账。空结果、HTTP 失败退款；结果不明保留费用。本地缓存、共用中的相同请求和翻页不重复收费。普通网页抓取和原图下载不虚构 API 费用，读取内容产生的模型 token 照常计费。

GPT 生图仍只受原有每日张数额度限制，不由这个 DeepSeek 费用余额阻断图片任务。模型安排画面等 DeepSeek 调用仍正常计入 API 费用；Codex 额度查询接口保留。

## 查看与重置

侧栏显示当前费用及各状态；连接设置可编辑日金额和可选群限额。活动详情的模型步骤显示费用与 token/cache 明细；联网步骤显示请求次数和人民币费用。同一模型返回的多个动作共享该次调用，不重复计费。

`POST /api/costs/reset`（旧 `/api/tokens/reset` 为兼容入口）仅允许已鉴权的主人调用。它释放当天已结算/估算的**本地额度**，保留账单、原始 token、请求次数、图片限额，以及进行中/未确认的费用。重置后界面显示已释放金额。它不会改变 DeepSeek 账户账单，也不会使未知费用消失。

## 旧账本升级

先停止应用 worker 并私下备份数据库，再构建，执行 `node scripts/migrate-cny.mjs /path/to/DeepSeekFish`。脚本只迁移香港日期当天，默认设置每日 ¥5；不发 API 请求、不清零今天的使用记录。新字段为增量迁移，重复执行不重复收费。进行中的旧请求会拒绝迁移；遇到相同 ID 的矛盾证据则原子回滚。

原模型 trace 必须通过 reservation ID、模型与当日时间精确关联。缺失 trace/usage 的旧模型预留保留为 unknown。旧联网账本不记录每笔退款金额，无法将汇总退款可靠对应到每个请求，因此旧联网项保留每次 ¥0.005 的 unknown 预留，不声称恢复了逐笔真实账单。旧 token 统计及日志不改写；次日正常从零额度开始。尚未迁移的当天旧账会阻止新增计费请求，避免悄悄绕过预算。
