# 贴吧模块

[全部文档](../README.md) · [项目首页](../../README.md)

贴吧接入复用 DeepSeek 原生工具、当前人格、知识库、探索队列和活动记录。模型决定看哪里、写什么、是否回应；账号权限、目标绑定和平台回执由程序处理。

## 当前工具

| 工具 | 能力 |
| --- | --- |
| `browse_page` | 读取公开帖子；必要时使用已有账号读取能力，结果注明访问方式 |
| `get_tieba_account` | 核实当前身份、实际关注列表、发布模式和申请授权范围 |
| `get_tieba_replies` | 读取发给本账号的公开回帖通知，包括楼中楼 |
| `publish_tieba` | 新主题 `thread`；统一回复 `reply`，按 `target` 自动盖新楼或发楼中楼 |
| `check_tieba_publication` | 用请求 ID 只读复查发布结果 |
| `apply_tieba_moderator` | 查看小吧主申请条件，或通过官网提交自己写的感言 |

**贴吧私信读取和发送尚未接入。** 回复通知不是私信收件箱，不能据此判断私信为空。小吧主申请也不提供任命、删帖或封禁能力。

## 运行与验证边界

公开内容通常不要求登录。写入需要当前已验证账号及管理员配置的权限；普通发言限定实际关注的吧，小吧主申请另有明确授权范围。新安装的普通发言默认预演，模型不能通过参数改成真实发布。

新主题使用官网原生发贴编辑器。已授权账号的普通回复和楼中楼也可以使用官网原生控件；未启用回复网页路径时保留 App Protobuf。不会因一次失败自动换通道重复提交。

已删除跨请求的 `publication-needs-human` 发布拦截。旧失败不冒充当前回执；真正验证码显示当前官方页面，由用户正常操作。平台接受、有回复 ID、公开可见和长期稳定是不同状态，见 [验证范围](validation.md)。

公开说明不包含生产账号、私人聊天、真实感言、请求 ID、私网地址或登录资料。源码位置见各模块末尾。
