# 真实自主发布的验收边界

本文件描述项目的验收机制和结论边界，不发布实际账号、聊天、回复正文、请求 ID、消费账单或生产部署记录。详细记录留在本机 WebUI 活动记录及私有 runtime。

## 使用生产模型流程

内部 simulated_owner_signal 入口把自然语言指令放入现有探索队列。它不是 QQ 网络消息，也不伪造 QQ 聊天记录。模型使用生产配置、当前人格、长期知识、历史背景及原生 Tool Calling，自己决定访问什么、选择目标、写内容并调用发布工具。

操作者不预先填写目标帖子、关注吧或正文，不直接调用发布接口代替模型完成验收。真实写入范围按本次明确授权记录，未获授权的后续尝试不能因测试需要而自动扩大。

## 实际证据

私有 trace 保存实际模型请求、工具定义、assistant/tool_call_id 配对、工具参数、真实回执、使用量与费用。出站记录区分请求未发出、平台拒绝、接受、未知、本人可见和公开可见。模型的私下总结不能替代实际请求计数和平台证据。

完整端到端成功必须同时具备：真实模型自主选择、正式 Provider 被调用、平台接受、有效 ID、非登录视角匹配正文，以及后续只读复查。一次成功不证明长期稳定。验证码失败不应被写成发布成功，整个探索会话结束也不等于发言成功。

## 当前实现

publish_tieba 的参数说明区分 thread、reply 和 comment；不支持 preview 或 mode 入参。QQ 与探索使用同源验证，传错时得到字段、原因和合法参数，参数错误不会被默默修成真实发布。

最新发言状态包含模型调用中未进入出站表的本地错误。WebUI 随既有状态刷新展示实际回执；官网有验证窗口时自动打开实时画面，用户可操作，不拿旧截图代替新请求。

跨请求的 publication-needs-human 拦截已删除。旧请求被拒或等待人工不能阻止新的独立请求；旧拒绝回执只作历史，不冒充新回执。账号权限、关注范围和发言运行模式仍来自现有配置。

## 发布版本与隐私

安装器记录基准代码版本及安装文件摘要，保留 Profile、SQLite、人格和长期记忆。部署前后不得用开发副本或 Mock 冒充正式进程。安装清单、运行证据和浏览器资料只留本机；公开仓库仅包含实现、公开技术来源和使用说明。

执行测试与实际发言均遵循用户当前指示。禁止额外测试时，只做必要构建和部署，不运行测试套件、触发模型试发或制造验证页面。
