# 连续任务链

肥鱼用 `activity_chain_start({messageNumber, steps, reply})` 建链。根据本轮主人的话规划 `steps`，每步写清任务和具体目标。需要先跟 GPT 小姐讨论时加 `discussion`，链落盘后才交接讨论。原有的 `nextStep` 仍可以作为单项后续指令使用。

任务进行到一半也可以用 `request_development({brief})` 讨论。把问题和查到的必要事实写进 `brief`。链自动保存当前进度，等到答复后在原步骤收到 `discussionForStep.reply`。发给主人的 QQ 消息使用 `send_message`。

常见用法是在 QQ 交代「先看看这个贴吧帖的 16 楼，确认合适的话回一条，最后按帖子主题画张图」。肥鱼把查帖、按指定楼层回复、画图排成三步。工具与自由探索共用，照常受各工具本身的配置影响。贴吧发言可用 `check_tieba_publication` 核对。只需发一条带默认配图的空间动态时可以使用 `mode: "qzone_post"`。

## 运行和交接

1. QQ 服务把计划、当前步骤、原消息来源写入 `fish.sqlite`。重投同一条主人消息会返回原来的链。
2. 无讨论时直接排队。需要讨论时，后台按链标记取对应答复，把答复交给第一步。讨论等待期间会释放执行租约，QQ 聊天和自由探索各自继续。
3. 肥鱼只执行当前一步。她先看真实工具回执，再用 `activity_chain_step_result({status:"completed",result:"实际结果与下步需要的 ID 或链接"})` 确认。结果和下一步位置一起保存，接手的执行轮会读到前面的结果。卡住时填 `status:"blocked"` 和卡点，后续步骤暂停。
4. `activity_chain_status({chainId})` 和 WebUI「活动记录 → 连续任务链」可查步骤、讨论答复和工具回执。查询成功返回 `ok: true`，链的历史失败留在 `chain.error`。两步之间重启从已保存的位置接着跑。执行中的工具调用中断会登记失败，避免自动重复发帖。

`activity_chain_status({})` 的 `active` 返回正在执行、排队、等待讨论或等待回执的链。主人私聊发 `/interrupt` 急停所有可停止的任务链，带完整链 ID 则只停一条。WebUI「活动记录」列出当前活动，可以逐条停止，或按「急停」中断当前任务链和自主探索。已经开始提交的内容继续核对平台回执。

每步独立计 24 轮，剩两轮时提交该步的实际结果或卡点。用 `remember_memory({title, text})` 写小记会关联当前链，可用 `read_memory({id: "chain:<链 ID>"})` 回查来源。

## 空间动态专用流程

- 每条链分享**当前讨论、当前机器人的 QQ 空间、一次动态**。收到结论后直接交给肥鱼写动态。发布前核对主人绑定、空间发布开关、账号和链状态。Codex 输出、网页和旧聊天作为写稿资料。
- 当前发布适配器需要图片。第一版使用主人给定的 `imageId`，或者为这类链配置一张已授权公开的默认图库图。沿用 `QQImageLibrary` 校验归属。这样通常无需再问主人，也无需额外生图。图不可用时保留草稿并报缺图。
- 草稿定稿后冻结正文和图片，保存发送摘要与用于查证的提交时间。每条链只存在一条发布记录，上传回执落盘后可复用。用现有 `publish(..., onSubmit)` 在网络提交前原子地把记录置为「提交中」。只有持有当前租约且成功更新状态的执行器能发出请求。
- 收到有效平台 ID 就确认。超时、掉线、重启或响应缺少 ID 就置为「结果待核对」。复用空间的只读查证，按同一账号、正文、提交后的时间及图片信息匹配。现有 `find` 只查最近 20 条并返回首个匹配，链路要保留匹配数或补充证据。查到唯一可信结果才确认，零条或多条都保留待核对。只有明确证明发布请求没发出时，才允许在原授权有效期内重试。

## 验收用例

| 场景 | 应看到的结果 |
| --- | --- |
| `activity_chain_start` 选择 `mode: "qzone_post"`，讨论完成且配图可用 | 自动生成草稿并发布一次，链状态有真实动态链接。 |
| 同一消息或讨论完成事件重投，两个执行器同时领任务 | 只有一条链和一次平台发布调用。 |
| 各步重启，尤其是保存草稿后和已提交未记回执时 | 草稿复用，已提交阶段走空间回读。 |
| 有两条相同正文动态，或 20 条窗口里没有记录 | 显示待核对，发布调用次数保持不变。 |
| 讨论失败、绑定改变、权限关闭、没有可公开配图 | 留下对应卡点。主人收到实际状态。 |
| 主人在已启用的群里直接唤醒肥鱼并交代多步工作 | 可直接建链。转发内容不算主人本轮指令。 |

先用 Mock 跑全链和重启用例，确认外部发布调用次数。上线试验单独用主人授权的一条测试动态，核对空间里实际出现的动态、对应 ID 和 WebUI 状态。
